# 🪑 FRITA – Furniture Brand Landing Page

**FRITA** is a modern, responsive landing page for a furniture brand, built using **Bootstrap 3.4**, **HTML5**, **CSS3**, and **JavaScript**. The site showcases stylish home furnishings with smooth design elements, visual layering, and basic form validation.

🔗 **Live Demo:** [ronax23.github.io/frita](https://ronax23.github.io/frita/)

---

## 🎯 Project Overview

This project simulates a homepage for a furniture or interior design brand. It features scrollable sections, animated design highlights, and overlapping layout elements created using positioning and pseudo-elements.

---

## ✅ Key Features

- 🪑 Elegant furniture brand design with modern aesthetic
- 🌀 CSS animations and transitions for a smooth user experience
- 🧩 Float-based layout using **Bootstrap 3.4** grid system
- 🧙‍♂️ Decorative elements using `::before` and `::after`
- 🧭 Overlapping layout using `position: relative/absolute`
- 📬 Contact form with **JavaScript validation**
- 📱 Mobile-friendly layout with responsive navbar

---

## 🛠️ Tech Stack

- **HTML5** — semantic page structure
- **CSS3** — styling, animations, pseudo-elements
- **Bootstrap 3.4** — float-based responsive grid and components
- **JavaScript (Vanilla)** form validation
